# 🌌 Interactive Solar System Explorer

An interactive educational web application that visualizes the Solar System with animated orbital motion of all eight planets around the Sun.

![Solar System](https://img.shields.io/badge/Solar%20System-8%20Planets-blue)
![React](https://img.shields.io/badge/React-19-61dafb)
![Tailwind](https://img.shields.io/badge/Tailwind-4-38bdf8)
![Canvas](https://img.shields.io/badge/HTML5-Canvas-orange)

## ✨ Features

- **Animated Orbits** — All 8 planets orbit the Sun with realistic relative speeds
- **Interactive** — Click or hover on any planet to see its details
- **Planet Info Panel** — View name, diameter, distance from Sun, orbital period, and description
- **Playback Controls** — Play/pause animation and adjust speed (0.1x to 10x)
- **Quick Select Sidebar** — Click planet names to instantly view their info
- **Beautiful Visuals** — Starfield background, planet glows, Saturn's rings, and smooth animations
- **Responsive** — Works on all screen sizes

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/solar-system-explorer.git
cd solar-system-explorer

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🛠️ Tech Stack

- **React 19** — UI framework
- **TypeScript** — Type safety
- **Tailwind CSS 4** — Styling
- **HTML5 Canvas** — Solar system rendering
- **Vite** — Build tool
